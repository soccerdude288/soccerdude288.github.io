Spec first

Write it down, then build it

Every project starts with a spec, a glossary, or a plan file that lives in the repo, so the agent and I agree on what we're making.

Agents as a system

Rules, skills, and hooks

Each repo carries an AGENTS.md or CLAUDE.md, reusable skills, and guardrails, so any session can pick the work back up.

Prove it

Tests and evals

Unit tests, recorded sample inputs, and end-to-end runs decide when something is done, not the chat.

Projects

ink. tattoo sleeve planner · web + iOS

Plan a full tattoo sleeve on a to-scale 3D model of your own arm. Place and resize pieces right on the arm, generate or upload flash art, and break the whole thing into sittings with hour and cost estimates. It started on the web, and the native iPhone app (SwiftUI and SceneKit) shares the same backend, with touch controls for orbiting the arm and sliding, pinching and twisting pieces on the skin.

Where the AI isAn assistant chat proposes designs, image models generate the flash, and a vision model turns reference photos into a description the image model can use. A photo-to-linework mode keeps the likeness of a real person or pet.

Live on the web, TestFlight on iPhone
Stack
React, Three.js, Vercel, SwiftUI, SceneKit, OpenAI + FLUX image models

Doll Dressup iPad dress-up studio for kids

A no-reading-required iPad app for kids 4 to 8. Each kid gets a profile and a collection of dolls to design, dress, pose in scenes, and snap in a photo booth with stickers.

Where the AI isThe doll art and outfit layers are generated with image models, then gated twice: a script checks the geometry of every layer, and a vision model role-plays a strict 6-year-old judge to catch muddy backgrounds, melted eyes and other things kids notice.
Status
In progress
Stack
SwiftUI (iPadOS), Python art pipeline, OpenAI + Gemini image models

Kroger MCP groceries for agents

My fork of the open-source kroger-mcp server, which lets AI agents search Kroger stores and products and manage a cart. I added an enriched cart view with live prices and stock, unit-price math that handles bulk and weight-sold items, and tools that suggest cheaper or in-stock substitutes for the whole cart. I also fixed token handling that was making 3 to 4 extra API calls per request.

Where the AI isAgents use it as hands: plan meals in chat and turn them into a priced grocery cart.
Status
Daily use
Stack
Python, FastMCP, Kroger API

Finlet Jellyfin for kids · iPhone, iPad, Apple TV, Android TV

A Jellyfin client built for families. Kids get big posters and tap-to-play, grown-ups get a calm full-featured mode. Per-kid rating limits, offline downloads, a math gate on settings, and server discovery that just works on the home network.

How agents built itOne SwiftUI codebase covers iPhone, iPad and Apple TV. Agents then ported it to Android TV, using the iOS app's test suite as the spec. The shared core is backed by more than 230 tests.

Tracker track anything, see what moves it

An iPhone app for tracking anything about yourself, from mood scales to yes/no habits, and finding out what actually changes it. A stats engine runs t-tests on events, correlations between trackers, and tag and weekday patterns, then turns the confident ones into insights and a printable doctor report. Widgets and Siri logging included.

How agents built itAgents worked through 30 milestones from a written plan. They ported a JavaScript prototype's stats code to Swift and checked it against golden test vectors made by running the original JS. More than 600 tests keep it honest.
Status
TestFlight prep
Stack
Swift 6, SwiftUI, SwiftData, WidgetKit, App Intents

Shelf Scanner thrift store title reader

Pan your iPhone slowly along a thrift store shelf and get back a clean, de-duplicated list of the book and DVD titles on it, ready to paste into an AI chat for price research.

Where the AI isOn-device Vision text recognition reads spines at two angles, then fuzzy matching merges the same title across frames and checks it against Open Library and TMDB. Recorded shelf pans act as evals for tuning.
Status
Proof of concept
Stack
Swift, SwiftUI, Vision, AVFoundation
